# Terminal Professional — Public Update Channel

قناة التحديث العامة (بلا توكن) لمشروع Terminal Professional.

- `update.json` — بيان الإصدار العام (JSON فقط، بلا مصادقة).
- `releases/build-<versionCode>/owner-release.apk` — حزمة الإصدار القابلة للتنزيل بلا مصادقة.

> هذا المستودع هو المرآة العامة التي ينشر إليها CI مباشرة؛ النسخة ذات `update.json`
> المبدئي تشير إلى إصدار القناة العامة الأصلي حتى يتوفر أول إصدار هنا.
